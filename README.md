# Trend Forge — AI Video Creator

A lightweight starter interface for an AI video creator. It includes:
- Trend/topic discovery placeholders
- Viral audio ideas
- Script generation UI
- Scene/storyboard builder
- Voice-over and subtitle controls
- Export/project controls

## Run
Open `index.html` in a browser. No installation is required for the demo interface.

## Important
This is a working front-end prototype. Real trend search, AI generation, text-to-speech, video rendering, and social publishing require API/service integrations.
